# ADR-0004: 位置・スタイル編集は「オーバーライド」として適用する

- **日付**: 2026-08-18
- **状態**: 採用

## 背景

AI 生成 HTML は flex / grid / absolute が混在する。
GUI から位置やスタイルを変えるとき、元のレイアウト機構を書き換えるとレイアウトが崩壊する。

## 選択肢

1. **元 CSS の該当ルールを書き換える** — 意図どおりの CSS になるが、
   セレクタの効き先が他要素にも及び、混在レイアウトが壊れる
2. **inline style に最小差分を上書きする** — 元の CSS を一切触らないが、
   inline style が積み上がり、生成 HTML としてはやや冗長になる

## 決定

案 2 を採る。

- ドラッグ移動は原則 `transform: translate(dx, dy)` の**追加**(元の配置プロパティに触らない)
- スタイル変更は対象要素の inline style へ最小差分で適用する
- 「元 CSS の該当ルールを直接書き換える」高度な編集は F14(コードビュー)とプラグインに委ねる

## 理由

元 CSS を書き換えないことは ADR-0001 の「触らなければ壊れない」の系。
セレクタ単位の書き換えは影響範囲がドキュメント全体に及び、
どの要素が巻き添えになるかを編集時点で予測できない。

## 影響

- インスペクタが扱えるのは inline style で表現できるプロパティに限られる
- 元 CSS 側の値は「継承された値」として読み取り専用で見せる
