# ADR-0007: 既知の課題の置き場を `docs/issues.md` に切り出す

- **日付**: 2026-08-23
- **状態**: 採用

## 背景

このリポジトリの `docs/` は docs-init の雛形から作られているが、**`issues.md` だけが存在しなかった**。
そのため「今マズいと分かっているが、まだ直していない」負債・妥協・設計書と実装のズレを
**全体で一覧する場所が無く**、それらは [roadmap](../roadmap.md) の「主要リスクと対応方針」・
[ideas](../ideas.md)・各機能の `decisions.md` に散っていた。
性質の違う 3 種類 — **将来起こりうるリスク / やると決めていない案 / 既に起きている負債** — が
同じ表に同居し、「今なにが壊れているか」を数えられない状態だった。

一方で [rules/development](../rules/development.md) §9 は
「Phase 進捗の正は roadmap、**この 2 つ以外にタスクファイルを作らない**」
「気付いた課題は roadmap の主要リスク表か ideas.md へ」と定めており
([ADR-0006](0006-docs-driven-migration.md) 裁定 5 の系譜)、
`issues.md` の新設はこの既存ルールと正面から衝突した。

## 選択肢

1. **既存ルール優先で作らない** — §9 のまま運用し、docs-init の doctor 検査 6(`issues.md` の未対応件数)は
   恒久的にスキップすると INDEX に明記する。追加コストはゼロだが、3 種類の同居は解消しない
2. **`issues.md` を新設し §9 を改訂する** — 置き場を 3 つに分け、境界を定義する
3. **新設したうえで roadmap の主要リスク表を解体する** — 既に起きている負債を全部 `issues.md` へ移送し、
   roadmap 側を将来リスク専用に絞る。SSOT としては最もきれいだが、移送の判断が主観に寄り、
   roadmap の記述を大きく書き換えることになる

## 決定

**選択肢 2 を採る。** `docs/issues.md` を新設し、§9 の「この 2 つ以外にタスクファイルを作らない」を
3 つに改訂する。境界の判定軸は **「もう起きているか」** の 1 本。

| 置き場 | 持つもの |
|---|---|
| [roadmap](../roadmap.md) | マイルストーン進捗(**進捗の正**)/ **まだ起きていない**リスクと対応方針 |
| [ideas](../ideas.md) | やると決めていない案(`features/` 昇格前の一時置き場) |
| [issues](../issues.md) | **もう起きている**負債・妥協・設計書と実装のズレ |

roadmap の「主要リスクと対応方針」表は**そのまま残す**(選択肢 3 は採らない)。

## 理由

- 判定軸を「もう起きているか」の 1 本に絞ったのは、境界が主観に落ちると必ず両方に書かれて
  SSOT が壊れるため。「深刻か」「直す気があるか」を軸にすると人によってブレる
- 選択肢 1 は「置き場が無いので roadmap のリスク表に書く」を続けることになり、
  リスク表が「起きうること」と「起きていること」の混在で読めなくなる方向に進む
- 選択肢 3 は移送の是非を 1 行ずつ判断する必要があり、今回の変更で背負う量として大きい。
  roadmap 側は無傷にし、**新しく気付いたものから `issues.md` に溜める**運用で移行する
- §9 が「タスクファイルを作らない」と縛っていたのは、**Phase 進捗の正が分散すること**を防ぐため。
  `issues.md` は進捗を持たない(状態は課題ごとの 4 値)ので、この意図とは衝突しない

## 影響

- docs-init の doctor 検査 6(`issues.md` の未対応 / 対応中の件数、深刻度「高」の放置指摘)が機能する
- 課題の置き場が 2 つから 3 つに増える。振り分けを迷ったら本 ADR の表に戻る
- [ideas](../ideas.md) に「もう起きている問題だと分かったら `issues.md` へ移す」経路が増え、
  移送した行は状態 `移送 → issues #n` で残る(行は消さない)
- roadmap の主要リスク表と `issues.md` は**今後ズレうる**。同じ事象が両方に書かれていたら、
  起きた時点で roadmap 側を `issues.md` への参照リンクに縮める
