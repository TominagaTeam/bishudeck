# fonts — 判断ログ

蒸し返し防止用。ここは「まだ仕様に昇格していない決定」と「経緯」の置き場。仕様の正は design.md。
全体に影響する判断はここではなく [../../adr/](../../adr/) へ。

## 記録基準

- **書く**: 議論して決めたこと / 代替案を退けたこと / 後で「なぜこうした？」になりそうなこと
- **書かない**: 自明な判断、コードを見れば分かること

## 運用

- 判断が覆ったら行は消さず、状態を `上書き → #n` にする（覆った経緯こそ蒸し返し防止に効く）
- 判断が仕様として安定したら **design.md 本文に反映**し、状態を `反映済` にする。AI が普段読むのは design.md 側で、ここは「なぜ？」と遡るときだけ読む

## ログ

| # | 日付 | 判断 | 理由 | 見送った代替案 | 状態 |
|---|---|---|---|---|---|
| 1 | 2026-08-23 | 無い書体は**グレーアウトせず候補から消す** | 「選べないが在る」と「そもそも無い」をユーザーは区別できない。選べないものを見せる理由が無い | グレーアウトして残す | 反映済 |
| 2 | 2026-08-23 | 実在判定は `document.fonts.check()` ではなく**幅の実測** | `check()` は `@font-face` で登録された書体について答える API で、ローカルにインストールされた書体については何も言わない。このカタログが並べているのは後者 | `document.fonts.check()` を使う(対象が違う) | 反映済 |
| 3 | 2026-08-23 | 総称は **monospace / serif / sans-serif の 3 つすべて**と比べる | macOS では `sans-serif` 自体が日本語ゴシックなので、和文書体を `sans-serif` とだけ比べると幅が一致し、在るのに「無い」と判定される | `sans-serif` 1 つと比べる(和文が全滅する) | 反映済 |
| 4 | 2026-08-23 | 既定の Noto Sans だけ**プローブしない**(`probe: null`) | ラテンと日本語を同じデザインで覆う唯一の書体だが、バンドルしないので実在するとは限らない。スタックは環境にある書体へ落ちるので、出しても嘘にならない | 他と同じくプローブする(未インストール環境で既定が消える) | **上書き → #5** |
| 5 | 2026-08-25 | **Noto Sans / Noto Sans JP を同梱する** | #4 の「出しても嘘にならない」が持たなかった。既定の名乗りを実測にした結果、この Mac では `既定(ヒラギノ角ゴシック)` になり、**ピッカーから Noto Sans が消えた**。「どの環境でも同じ字形」が目的なのに、既定がいちばんそれを満たしていなかった | 同梱しない(見た目が機械ごとに変わり続ける)/ 実行時に Web から取る(オフラインで壊れる) | 反映済([ADR-0010](../../adr/0010-bundle-two-typefaces.md)) |
| 6 | 2026-08-25 | 配信は **`slides://`**。フロント側(`public/`)には置かない | プレビュー iframe は `allow-same-origin` を持たない不透明オリジンで、Tauri がフロントに返す `Access-Control-Allow-Origin` はウィンドウのオリジンそのもの。**編集中は読めてプレビューだけ黙って落ちる**。`slides://` は元から `*` を返す | `public/fonts/` に置く(プレビューが落ちる)/ Rust に CORS 付きの別ポートを立てる(スキームが 1 つ増える) | 反映済 |
| 7 | 2026-08-25 | 同梱書体は **`bundled: true` で実測の対象外**にする | 手心ではなく、測ると誤答するため。実測はアプリ窓の canvas でやるが、`@font-face` が載るのはスライドを描く文書のほう。**ステージで完璧に描ける書体が「無い」と見える** | `document.fonts.load()` を待ってから測る(タイミング依存が増え、答えは同じ) | 反映済 |
| 8 | 2026-08-25 | 埋め込み表は **`build.rs` がディレクトリ走査**して作る | 140 ファイルある。手書きすると書体を足すたびにコードを触ることになり、CSS とコードの二重管理になる | `include_dir` crate を足す(依存が増える)/ Tauri の `resources` にして実行時に読む(実行時エラーの経路が増える) | 反映済 |
| 9 | 2026-08-25 | `font-display` は `swap` ではなく **`block`** | ローカル配信なので待ちはほぼ無い。`swap` だと代替書体で 1 度描いてから差し替わり、**その間の実測値でハンドルの位置が決まる** | Fontsource の既定 `swap` のまま(選択ハンドルがずれる瞬間ができる) | 反映済 |
