# inspector — 判断ログ

蒸し返し防止用。ここは「まだ仕様に昇格していない決定」と「経緯」の置き場。仕様の正は design.md。
全体に影響する判断はここではなく [../../adr/](../../adr/) へ。

## 記録基準

- **書く**: 議論して決めたこと / 代替案を退けたこと / 後で「なぜこうした？」になりそうなこと
- **書かない**: 自明な判断、コードを見れば分かること

## 運用

- 判断が覆ったら行は消さず、状態を `上書き → #n` にする
- 判断が仕様として安定したら **design.md 本文に反映**し、状態を `反映済` にする
- **番号は識別子であって順序ではない。** 表は番号順に並べるが、日付は列で読む ——
  #71 は 2026-08-23 の判断で、当時 `#15` を**二重に振っていた**のを
  2026-08-26 に採り直したもの（他所から `decisions.md #15` と名指しされている 6 箇所は
  すべて浮遊ツールバーの廃止を指していたので、そちらを #15 のまま残した）。
  **番号は他のドキュメントから名指しされる外部インターフェースなので、既存の番号は動かさない**

## ログ

インスペクタ本体の判断 #1〜#9 は、この設計書ができる前に
[editing-engine/decisions.md](../editing-engine/decisions.md) に記録された(uid を添えた computed の読み取り、
フォーカス時点での uid 退避、塗りの「透明 / 単色」、border のロングハンド、太さの即時反映など)。
**移していない** — 判断ログは「いつ・どういう文脈で決めたか」の記録なので、
番号を振り直すと当時の並びが読めなくなる。ここには新しい行だけを足す。
