# persistence — 処理フロー

## メインフロー（自動保存）

```mermaid
graph TD
    A[ドキュメントが変わる] --> B{dirty かつ保存先あり?}
    B -->|いいえ| C[何もしない]
    B -->|はい| D[schedule 2 秒]
    D --> E{書き込み中?}
    E -->|はい| F[again を立てて待つ]
    E -->|いいえ| G[composeDocument]
    G --> H[tmp へ書く → rename]
    H --> I{その間に変わった?}
    I -->|いいえ| J[markSaved]
    I -->|はい| K[dirty のまま]
    F --> D
```

## 異常系・エッジケース

| ケース | どうなるか |
|---|---|
| 書き込みに失敗 | `error` イベント → トースト。次の書き込みは止めない |
| 書き込み中にさらに編集 | `#again` で覚え、終わってから再スケジュール |
| 書いている間にドキュメントが動いた | `markSaved` しない。「保存済み」と嘘をつかない |
| ブラウザで動かしている(`npm run dev`) | `getCurrentWindow()` が例外 → 閉じる監視だけ諦める。自動保存自体は走る |
| 書き出しダイアログを閉じられた | `dirty` が残るので閉じない |
| 取り込んだ HTML が UTF-8 でない | `from_utf8_lossy`。1 バイトのせいで取り込みが止まるほうが困る |

## 状態遷移

```mermaid
stateDiagram-v2
    [*] --> 未保存: 取り込み直後
    未保存 --> 保存済み: 書き出し(場所を選ぶ)
    保存済み --> 変更あり: 編集
    変更あり --> 保存済み: 自動保存 / ⌘S
    未保存 --> [*]: 終了時に 3 択で訊く
    変更あり --> [*]: 黙って書いてから閉じる
```
