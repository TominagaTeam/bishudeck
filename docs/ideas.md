# アイデア置き場

「思いついたけど、まだやると決めていない」ものの一時置き場。`features/` に昇格する前段。
未確定のまま溜まるのは健全な状態（doctor の検査対象外）。

## 運用

- 会話で出た「いつかやりたい」「こうできたら」は AI がここに書き留める
- **やると決めた** → `features/<機能名>/` を作成し、状態を `採用 → features/<機能名>` に
- **全体方針に関わる** → ADR に昇格
- **やらないと決めた** → 状態を `見送り` にして理由をメモに追記（行は消さない。蒸し返し防止）
- **「案」ではなく、もう起きている問題だと分かった** → [issues.md](issues.md) へ移し、状態を `移送 → issues #n` に（判定軸は「もう起きているか」。[ADR-0007](adr/0007-issues-md-and-task-file-rule.md)）
