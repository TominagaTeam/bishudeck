01CONCEPT

Never break the HTML you opened.

The premise: whatever the editor does not understand stays exactly as it was, as long as you leave it alone. So even an elaborate AI-generated deck comes back looking the way it did — open it, fix it, export it.

HTML is the source of truth

There is no project format to convert to. From start to finish, the thing you work on is one HTML file.

CSS and JS are preserved

Scripts are paused while you edit, so touching things is safe; when you present, everything runs exactly as written. Animations included.

Changes sit on top

The original CSS is never rewritten. A moved position or a changed color is layered on as the smallest possible override.

04SELECT & MOVE

Select, then move.

Select
  • Click to select one element. Exactly one is selected at a time
  • When something is in the way, Alt+click, or right-click for “Elements at this point”
  • Tab moves to the next element, Esc steps one level out
  • Hover the breadcrumb in the inspector to see that element outlined with a dashed line
Move
  • Drag to move, use the handles to resize, and the top handle to rotate
  • Edges snap to those of nearby elements
  • ←→↑↓ nudges by 1px; add Shift for 10px
  • Hold Alt while dragging, or press ⌘D, to duplicate

05TEXT

Text starts with a double-click.

The caret lands where you clicked, with that word selected. Click outside the box, or press Esc, to leave.

Select the element: all of it

With an element selected, the inspector’s “Text” panel applies to the whole of it. Anything that is a paragraph property, like alignment, always applies to the whole element.

Select a range: just that

Once you are editing, a selected range takes color, highlight and weight on its own. Editing continues while you use the panel — the selection does not go away.

Enter and F2 also start editing. When you leave, the element stays selected, so you can nudge it with the arrow keys right away.

07IMAGES

Put a photo in an empty box.

Any box that holds neither text nor an image can be a photo frame. The “photo placeholder” areas of an imported deck work the same way.

Drop it in

Drag an image file onto the box. This is the way in when the app is running on the desktop.

Right-click

Right-click the box and choose “Insert image”. A file dialog opens. The inspector’s “Image” panel offers the same thing.

Crop

Two rectangles — the frame and the image — decide what shows. Whatever falls outside is hidden, never thrown away.

Replacing and cropping are each a single Undo. Reopen the exported HTML and the crop comes back exactly as it was.

08PRESENT & SAVE

Show it. And keep it.

Present

F5 opens a separate full-screen window. Page with ←→ or a click; leave with Esc. Here, JavaScript runs exactly as written.

Save

⌘S exports a single HTML file. Once a deck knows where it lives, it autosaves to that file whenever your hands pause for two seconds.

A deck you have only imported is never overwritten on its own. Only when you close without choosing a destination does it ask: “Export and quit / Quit without exporting / Cancel”.
