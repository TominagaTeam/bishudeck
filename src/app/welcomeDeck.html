WELCOME1 / 11
01CONCEPT

読み込んだ HTML を、壊さない。

このアプリの前提は「エディタが解釈できないものは、触らなければそのまま残る」こと。だから AI が書いた凝ったデッキも、開いて直して書き出すだけで元の見た目のまま戻ります。

HTML がそのまま正

独自のプロジェクト形式に変換しません。扱うのは最初から最後まで 1 枚の HTML ファイルです。

CSS と JS は保持

編集中はスクリプトを止めて安全に触り、再生では書かれたとおりに動かします。アニメーションもそのまま。

変更は上書きで載せる

元の CSS は書き換えません。動かした位置や変えた色だけを、最小の差分として上に重ねます。

02GETTING STARTED

操作はこの 3 つだけ覚えれば足ります。

取り込んで、直して、書き出す。ファイルはずっと HTML のままなので、保存と書き出しの区別もありません。

取り込む

ツールバーの「HTML を取り込む」から選ぶだけ。スライドの切れ目は自動で判定し、確認してから分割します。

⌘O
02

直す

クリックで選び、ドラッグで動かし、ダブルクリックで文字を打ち替える。細かい値は右のインスペクタで。

ダブルクリック
03

書き出す

1 枚の HTML として書き出します。一度書き出したデッキは、手が 2 秒止まると同じ場所へ自動保存。

⌘S

04SELECT & MOVE

選んで、動かす。

選ぶ
  • クリックで 1 つ選択。選べるのは常に 1 つです
  • 重なって選べないときは Alt+クリック、または右クリックの「この位置にあるもの」
  • Tab で隣の要素へ、Esc で 1 階層外へ
  • インスペクタのパンくずに触れると、その要素が破線で光ります
動かす
  • ドラッグで移動、ハンドルでリサイズ、上のハンドルで回転
  • 他の要素の辺に近づくと吸着します
  • ←→↑↓ で 1px、Shift を足して 10px
  • Alt を押しながらドラッグ、または ⌘D で複製

05TEXT

文字はダブルクリックから。

キャレットはクリックした位置に入り、その語が選択された状態で始まります。抜けるのは枠の外をクリックするか、Esc を押したとき。

選ぶだけなら、要素ぜんぶ

要素を選んだ状態でインスペクタの「文字書式」を当てると、その要素の全体に効きます。行揃えのように段落の性質を変えるものは、いつでも要素全体です。

範囲を選べば、そこだけ

編集に入ってから範囲を選ぶと、色・蛍光・太さはその範囲だけに効きます。パネルを触っているあいだも編集は続き、選択範囲は消えません。

Enter や F2 でも文字編集に入れます。抜けたあとは要素の選択が残るので、そのまま矢印キーで動かせます。

数値で決めたいときは、右のパネル。

位置とサイズX / Y / W / H / 回転
ボックス背景・余白・角丸
枠線種類・色・太さ

07IMAGES

空いている箱に、写真を入れる。

文字も画像も持たない箱なら、どれでも写真枠として使えます。取り込んだデッキの「写真添付エリア」も同じ扱いです。

落として入れる

画像ファイルを箱の上にドラッグ＆ドロップ。デスクトップアプリとして起動しているときの入口です。

右クリックで入れる

箱を右クリックして「画像を入れる」。ファイル選択が開きます。インスペクタの「画像」からも同じ操作ができます。

トリミングする

枠と画像の 2 つの矩形で切り抜きます。はみ出た部分は隠れるだけで、捨てられません。

入れ替えもトリミングも Undo 1 回で元どおり。書き出した HTML を読み直しても、同じ状態で戻ります。

08PRESENT & SAVE

見せる。そして、失わない。

再生する

F5 で別ウィンドウが全画面で開きます。ページ送りは ←→ とクリック、終了は Esc。ここでは JavaScript も書かれたとおりに動きます。

保存する

⌘S で 1 枚の HTML に書き出します。行き先が決まったデッキは、手が 2 秒止まるたび同じファイルへ自動保存されます。

取り込んだだけのデッキは勝手に上書きしません。書き出し先を決めていないまま閉じようとしたときだけ、「書き出して終了 / 書き出さずに終了 / キャンセル」を聞きます。
